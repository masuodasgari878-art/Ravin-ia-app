# backend

سرویس‌های بک‌اند.

- `authentication` — ثبت‌نام، ورود، توکن و نشست
- `users` — پروفایل، اهداف و تنظیمات
- `nutrition-engine` — TDEE، ماکروها و قوانین تغذیه
- `food-engine` — دیتابیس غذا، جستجو و نگاشت مواد
- `meal-engine` — ترکیب وعده و منوی روزانه/هفتگی
- `portion-engine` — محاسبه و تعدیل سهم
- `progress-engine` — وزن، پایبندی و روند
- `ai-orchestrator` — هماهنگی مدل‌ها و پاسخ مربی
